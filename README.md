## 同步电机曲线 · 2026-11-13

- 按用户后续纠正，仅直接输入标幺电阻、Ld、Lq、磁链；不保留额定值换算、反电动势输入或机型预设。转速在图右侧竖向调节，范围 −2～2 pu。
- 演示默认值为Rs=0.02、Ld=0.20、Lq=0.40、磁链=0.80 pu，不对应具体型号。Rs滑块固定0～0.5，Ld/Lq/磁链滑块固定0～2；四个文本框允许任意有限非负值，不设固定上限。超出滑块范围时保留文本值用于计算，不扩大滑块范围，也不反向钳位文本值；超出浮点计算能力时明确提示。

- 两页恒转矩默认范围−3～3 pu、间隔0.2 pu，含15条负转矩、零和15条正转矩，共31条。转子页下拉可恢复默认组或选择原有正负预设，也可手填逗号分隔的正、负、零值，支持±写法，最多32个去重后的有限值；默认范围不限制自定义输入，不恢复仅靠ΔT自动铺线。两页“恢复默认参数”同时恢复该转矩列表。无效列表提示后保留上一次有效图。

## VF电压定向 · 2026-11-13

入口：[页面/电机控制/同步电机/VF工作点分析.html](页面/电机控制/同步电机/VF工作点分析.html)。与转子定向页属于同一电机页面族，复用稳态模型、本地绘图库、基础样式与实时预览器，不复制第三方库，也不引入依赖。

- 定子电压定向采用Ud=Uout、Uq=0，Iq一般不为0。原始请求中的“Iq=0”与电压定向不是同一约束，本轮按Uq=0实现并保留Iq=0参考线；额外强制单位功率因数不属于已实施控制律。
- 本页采用示例规律 `Uout=min(Umax,Uboost+kVF*abs(omega))`，频率−2～2 pu，电压上限与电流边界可编辑。δ定义为电压矢量相对转子d轴的角度，默认110°；改变δ是在同步稳态族中选择工作点，不表示开环VF能测量或控制转子相角。
- 先以转子电压 `vd=Uout*cos(delta)`、`vq=Uout*sin(delta)` 求解原模型，再旋转到电压坐标。保留电流幅值、转矩、有功、无功与视在功率；默认点约Id,u=0.733686、Iq,u=0.060826、T=0.576109 pu。
- VF轨迹为固定Uout和频率下所有δ的电流集合；电流边界、恒转矩/PF线、五种底色独立设置。MTPA（绿色）、MTPV（紫红色）在主图层栏默认开启，转矩列表留在参考面板。功率场采用 `P=Uout*Id,u`、`Q=-Uout*Iq,u`、`Pmech=P-Rs*I^2`、`T=Pmech/omega`；只有电压轨迹上的点同时满足电机方程，轨迹外底色不是可实现工作点。MTPA/MTPV是不同电压幅值的参考族，不是当前VF约束。
- 初始取景及“恢复初始视图”会纳入电流边界、当前工作点，以及当前输出电压/电压上限上的正负转矩优化参考点，使MTPA/MTPV实际进入视野；调速时保留手动视野，不强行缩放。恒定参数的转子dq MTPA本身不含转速项，但本页的电压坐标转换使用当前转速；MTPV按包含Rs和当前转速的电压方程求解。参考轨迹可延伸出屏幕，不表示全部参考点都在电流限值内。
- 零电压不定义电压定向；零速不由功率除以频率反推T，但有直流补偿时工作点转矩仍由转子方程求得；奇异方程不伪造唯一电流。选定点对应的平衡负载等于所显示的电磁转矩（忽略机械损耗），不包含启动、失步和机械动态，不作稳定性保证。
- 拖动、参数滑块与相角滑块沿用WebGL/Canvas预览和CPU精度回退；相角变化只移动工作点，复用轨迹缓存。直接打开HTML可离线绘图。
- 最终九文件回归78通过、0失败、0跳过。含8项VF模型测试（独立SPMSM解析圆、正反转/零速、电压旋转、功率平衡、退化、不可达转矩，以及独立720角扫描核验MTPA/MTPV极值）及真实Edge的默认曲线可见域/SVG路径、独立显隐、调速更新与视野保持、原生转速/相角实时拖动、5种GPU像素、上下文丢失CPU像素、低幅值自动色标、4种一屏窗口、主题与阻断外网文件加载。无磁链且Ld=Lq时明确提示优化曲线无唯一解。证据：[临时测试/2026-11-13-VF工作点/VF验收.json](临时测试/2026-11-13-VF工作点/VF验收.json)。

## 多电压与负转矩 · 2026-11-13

### 负阻尼与 PI 稳定性分析 · 2026-10-24

阻尼允许在 −4 至 4 之间调节。默认展示同一负阻尼对象的发散情形，另有稳定边界、PI稳定及摩擦局部稳定预设。稳定分析面板显示目标处有效阻尼、稳定余量、两个极点及最大实部；可在Kp–Ki图中点击或用方向键调整增益，也可一键设到临界Kp或稳定侧。

固定目标处，beff = b + (Fc/vε)·sech²(r/vε)，闭环线性化特征方程为 Mλ² + (Kp+beff)λ + Ki = 0。M>0 时，Ki>0 且 Kp+beff>0 保证局部渐近稳定；Kp+b>0、Ki>0 是此平滑摩擦模型全局渐近稳定的充分条件。例如 b=−1、Fc=0、Ki>0 时，Kp<1发散，Kp=1等幅振荡，Kp>1渐近收敛。灰色曲线区分实极点与复极点，不是失稳边界。有摩擦且极点落在虚轴上时，明确标注线性化无法判断非线性稳定性；Ki=0单独说明。

本版采用负阻尼保持二维自治相图，没有加入纯延迟；纯延迟需要状态历史，不能仅由当前(F,v)确定流向。发散轨迹达到|F|或|v|≥1000时，在真实积分时间停止并提示；不钳位为假平衡点，也不延长剩余时段的曲线。

### 渐隐轨迹流场 · 2026-10-24

背景箭头与六条长背景轨迹已替换为有限时间短轨迹。起点最深，向前演化逐渐变淡；真实积分时长可选0.25至5秒，疏密分5档。背景流场同步动态展开、淡出后重播，可独立暂停或显示完整轨迹。主轨迹时间轴不受背景设置影响。离开视窗的短轨迹停止，后台或离屏暂停动画，系统要求减少动态效果时默认静止。

散度为 −[Kp+b+(Fc/vε)·sech²(v/vε)]/M。蓝色段表示负散度、橙色正散度、灰色接近零。起点模式包括均匀、|散度|加密、散度平方加密；确定性分层采样在速度方向按加权累积分布布点，总数保持相同，基础权重保留低散度区域，最大密度比6:1。无摩擦或可见域散度恒定时自动退化为相同均匀点集。高DPI/大窗口下最多576个起点，并缓存几何和按时间分组的SVG路径。

线密度用于观察流向与汇聚趋势，并非概率密度。加密模式还包含起点分布的影响；散度也不单独等同于全局稳定性。数学说明与来源见页面底部。
