模型定义

用于分析同步电机在转子DQ坐标中的稳态工作点、功率与约束曲线。非角度量均为标幺值，演示参数不对应具体电机型号。

约束域为 |I|≤电流上限 与 |U|≤电压上限 的交集。MTPA表示固定电流幅值下的最大/最小转矩轨迹；MTPV表示计入电阻与当前转速的固定电压幅值极值轨迹。

电流、电压矢量采用各自标幺基准，共用d/q方向。电压色图逐点反算电流；等值线及约束域属于电流平面，电压映射线由源电流轨迹前向计算。不同坐标的矢量端点不代表同一物理量。

vd = r id − ω lq iq · vq = r iq + ω(ld id + ψ)
T = [ψ + (ld − lq)id]iq
Pmech = ωT · P = Pmech + r|i|² · Q = vqid − vdiq · S = |v||i| · PF = P/S

φ=θ电压−θ电流=atan2(Q,P)，PF=cosφ；δ为电压相对转子d轴的角度。角度取[−180°,180°)，零矢量方向未定义。Q采用上述有向定义。

模型不计铁耗、机械损耗、磁饱和与温度变化，不用于判定启动过程或动态稳定性。奇异或无唯一解时不绘制相应结果；拖动超出有效解范围时保留最后有效状态。
