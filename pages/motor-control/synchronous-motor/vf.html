模型定义

用于分析定子电压定向坐标中的同步电机稳态工作点。Ud,u=Uout，Uq,u=0，Iq,u一般不为0；非角度量采用标幺值。电压与频率独立指定。

φ为电压与电流的有向夹角，PF=cosφ；δ为电压相对转子d轴的角度。转子dᵣ、qᵣ方向分别为−δ和90°−δ。零电压无定向，零电流无电流方向；两种矢量采用各自标幺基准。

约束域包含电流限值内、存在0<U≤指定电压稳态解的电流点；固定电压工作点仅位于对应电压轨迹上。等转矩参考线不代表实际工作点已满足该负载。

Uout = U设定（与频率独立）
δ = θ电压 − θ转子
转子电压 vd = Uout cosδ，vq = Uout sinδ
Id,u = id cosδ + iq sinδ，Iq,u = −id sinδ + iq cosδ

P = Uout Id,u · Q = −Uout Iq,u · S = Uout |I|
Pmech = P − Rs |I|² · T = Pmech / ω（ω≠0）

U/T/P/Q色图及恒转矩线采用从零电流点U=|ωψf|出发的径向连续稳态分支，各点使用自身所需电压。无可靠延拓、折点或零电压边界处留空；零速或零磁链时无原点方向锚点。数值留白不等于物理无解，也不代表已覆盖所有连通分支。

“电流边界”为原点连续分支的边缘：橙色实线表示F=0且∂F/∂δ=0的逆解折点，虚线表示U→0的定向极限。它不是设定电流上限的圆，也不是所有分支的绝对电流上限。MTPA/MTPV为对应转速下的极值参考轨迹。

本模型不包含机械动态、启动或失步过程，不作动态稳定性判断。电机参数为演示值；相角是分析参数，不代表实机控制或测量能力。拖动遇到无解或奇点时保留最后有效状态。
