参考线

蓝色点线为参考电压，粗实线为当前电压。零电压没有电压方向，不绘制定向轨迹。底色与恒转矩线仅对应当前电压，不能用于读取其他电压曲线的转矩。

模型定义

采用同步稳态、定子电压矢量定向坐标：Ud,u=Uout，Uq,u=0。Iq,u一般不为0；Iq=0参考线在Id>0时为PF=1，在Id<0时为PF=−1。全部量为标幺值。

Uout = min(Umax, Uboost + kVF |ω|)
δ = θ电压 − θ转子
转子电压 vd = Uout cosδ，vq = Uout sinδ
Id,u = id cosδ + iq sinδ，Iq,u = −id sinδ + iq cosδ

kVF是标幺电压对标幺频率的斜率，不是转矩系数。例如kVF=0.8、频率0.5 pu，无补偿且未限幅时，输出电压为0.4 pu。原“VF轨迹”表示当前电压下的电流工作点集合，不是电压随频率或时间变化的曲线。

蓝色粗实线为当前电压，点线为默认0.2～2 pu、间隔0.2的参考电压族。每条曲线保持自身电压幅值与当前频率，改变δ后先求解原转子dq稳态方程，再旋转电流；参考电压不被Umax限幅。相角是分析参数，并不意味着开环VF能控制或测得转子相角。选定工作点所需的平衡负载等于显示的电磁转矩（未计机械损耗）；没有机械动态、启动、失步或稳定性判定。

P = Uout Id,u · Q = −Uout Iq,u · S = Uout |I|
Pmech = P − Rs |I|² · T = Pmech / ω（ω≠0）

底色与恒转矩线是当前Uout下的功率平衡关系，只有当前电压轨迹上的点同时满足该VF给定的电机方程；不能把底色或恒转矩线的数值读到其他电压参考曲线上。零速不由功率推算转矩，实际点仍由转子方程求T。零电压无电压定向，奇异方程不伪造唯一工作点。MTPA/MTPV为不同电压幅值下的参考族经逐点旋转所得，并非当前电压轨迹。

恒定参数模型的转子dq MTPA由电感和磁链决定，不直接依赖转速；这里的电压坐标投影使用当前转速。MTPV按包含Rs与当前转速的电压方程求极值。初始取景包含当前边界上的优化参考点，不表示整条无界参考轨迹都在屏幕内，也不表示所有参考点满足电流上限。
