模型定义

采用同步稳态、定子电压矢量定向坐标：Ud,u=Uout，Uq,u=0。Iq,u一般不为0。电压与电流的有向夹角φ=θ电压−θ电流=atan2(Q,P)，不同于电压相对转子d轴的δ；φ以度数显示，PF=cosφ仅作为计算关系。非角度量采用标幺值。

φ背景从−180°到150°每30°一条，180°与−180°重合不重复。在电压坐标中，φ线是方向为−φ的单向电流射线；零电压或零电流时夹角未定义。

约束域要求电流不超过当前电流边界，并存在满足完整电机方程的正电压解，且该电压不超过当前输出电压。这里允许电压在上限以内变化；固定电压的状态仍只在对应轨迹上。多解时任一满足限制的分支均可计入，不能一般地把闭合曲线外侧都当作低压可达区，也不保证动态稳定。

两个矢量采用各自的标幺基准，并统一显隐；电压端点为(Uout,0)，不是该画布位置的电流工作点。未锁定时电流点在有效域内自由拖动，沿原解分支反算电压和δ；电压给定、δ及转矩随实际状态更新，电流边界与φ参考值不变。只有勾选恒电压时才固定电压幅值。无解、折点或零方向奇点保留最后有效状态。

灰色箭头dᵣ、qᵣ表示转子正d/q方向。在电压定向坐标中，转子d轴方向角为−δ，q轴为90°−δ；方向随δ实时变化。电压定向或方程无定义时不绘制方向。

表内锁定最多一项，再次点击可解除，捕获当前工作点的|U|、|I|、T或PF，不锁坐标分量或附加另一个隐藏约束。电流锁定沿圆、PF锁定沿当前有向射线、转矩锁定按完整逆解等值条件投影；电压可随其他锁定下的移动变化。保持原有效解分支，参数修改不兼容时退回上一状态，不跳到其他解。

Uout = U设定（与频率独立）
δ = θ电压 − θ转子
转子电压 vd = Uout cosδ，vq = Uout sinδ
Id,u = id cosδ + iq sinδ，Iq,u = −id sinδ + iq cosδ

本页直接指定电压，不使用压频比、低速补偿或VF限幅。电压轨迹表示当前电压和频率下的电流工作点集合，不是电压随频率或时间变化的曲线。默认电压0.8 pu；改变频率不自动改变该电压。

电压参考族默认0.2～2 pu、间隔0.2。每条曲线保持自身电压幅值与当前频率，改变δ后先求解原转子dq稳态方程，再旋转电流；参考电压与当前给定独立。电流圆仍是约束边界，不是另一独立驱动源。选定等转矩线不意味着实际工作点已满足该负载。相角是分析参数，不代表能控制或测得实际转子相角；没有机械动态、启动、失步或稳定性判定。

P = Uout Id,u · Q = −Uout Iq,u · S = Uout |I|
Pmech = P − Rs |I|² · T = Pmech / ω（ω≠0）

全平面颜色图提供所需电压U、转矩T、有功P和无功Q。非零转速、非零磁链时，从零电流点U=|ωψf|、T=P=Q=0沿径向自适应小步延拓同一稳态分支；不逐点按电压大小跳支，不用当前电源电压给全平面赋值。各点采用自身电压计算P=U Id,u、Q=−U Iq,u及完整转子方程转矩。

颜色图不随当前电源给定、δ或电流上限变化。无解、零电压边界、折点或无法可靠延拓的区域留空，不跨接其他分支；这只表示当前径向延拓确认的区域，不宣称找全所有可绕行到达的连通域。零速或零磁链时缺少原点电压方向锚点，色图留空并提示。恒转矩参考线仍对应当前给定电压，约束域另行表示限值；全平面颜色不保证动态稳定。

恒定参数模型的转子dq MTPA由电感和磁链决定，不直接依赖转速；这里的电压坐标投影使用当前转速。MTPV按包含Rs与当前转速的电压方程求极值。初始取景包含当前边界上的优化参考点，不表示整条无界参考轨迹都在屏幕内，也不表示所有参考点满足电流上限。
