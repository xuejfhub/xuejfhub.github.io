📚 稳态方程、求解方法与公式

一、T 型等值电路（频域复相量，频率为 $\omega_s$，转差率 $s$）

定子漏阻抗：\(Z_s = R_s + j\omega_s L_{ls}\)；转子支路阻抗：\(Z_r = \dfrac{R_r}{s} + j\omega_s L_{lr}\)；励磁阻抗：\(Z_m = j\omega_s L_m\)。

二、求解步骤（由 $\tilde U_s$ 解出所有量）

① 励磁支路与转子支路并联：\(Z_p = \dfrac{Z_m \cdot Z_r}{Z_m + Z_r}\)；总输入阻抗 \(Z_{in} = Z_s + Z_p\)。

② 定子电流：\(\tilde I_s = \dfrac{\tilde U_s}{Z_{in}}\)。本页取 $\tilde U_s$ 沿实轴方向为相位参考。

③ 气隙电压（并联支路端电压）：\(\tilde U_m = \tilde U_s - Z_s\tilde I_s\)。

④ 由 KCL 分流：\(\tilde I_r = \dfrac{\tilde U_m}{Z_r}\)，\(\tilde I_m = \dfrac{\tilde U_m}{Z_m}\)，且 \(\tilde I_s = \tilde I_m + \tilde I_r\)。

三、磁链（由 $\tilde\psi = \tilde U_L / j\omega_s$，或 $\tilde\psi = L\tilde I$）

气隙磁链：\(\tilde\psi_m = L_m\tilde I_m = \dfrac{\tilde U_m}{j\omega_s}\)；

定子磁链：\(\tilde\psi_s = L_{ls}\tilde I_s + \tilde\psi_m\)；转子磁链：\(\tilde\psi_r = L_{lr}\tilde I_r + \tilde\psi_m\)。

四、电磁转矩与功率

电磁（气隙）功率：\(P_e = |\tilde I_r|^2 \cdot \dfrac{R_r}{s}\)；电磁转矩：\(T_{em} = \dfrac{P_e}{\omega_s}\)（标幺值，同步速基值）。

机械功率：\(P_m = (1-s)P_e\)；输入功率：\(P_{in} = \mathrm{Re}\{\tilde U_s \tilde I_s^*\}\)；功率因数：\(\cos\varphi = P_{in}/|\tilde S|\)。

五、转子频率控制模式（本页核心）

转子电流频率 \(f_r = s\cdot f_s\)（即转差频率）。给定 $f_r$ 时，\(s = \dfrac{f_r}{f_s}\)。

物理意义：保持 $f_r$ 不变，单独调 $U_s$ 时电流线性变化；若同时按 $U_s/f_s$ 恒定调节，则主磁通近似恒定、电流近似不变——这正是 恒 V/f 标量控制 的原理。

六、转速关系

同步速 $n_s = 1$（pu），转速 \(n = (1-s)\,n_s\)。

注：标幺值系统中 $\omega_s(\text{pu}) = f_s(\text{pu})$，电抗 $X = \omega_s \cdot L$；磁链基值 $\psi_{base} = U_{base}/\omega_{base}$。 本页计算经过 Python 数值独立验证（默认参数 $s{=}0.03$ 下 $|I_s|{=}0.856$、$T_{em}{=}0.632$）。
